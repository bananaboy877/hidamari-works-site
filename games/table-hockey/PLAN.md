# テーブルホッケー — 勝敗演出と音声追加プラン

## ゴール

10点先取制の勝敗判定を入れ、勝利/敗北の演出(オーバーレイ + ボイス)とパドルヒット音・ゴール音を追加する。試合終了後はマウスホイール入力で次の試合に進む。

---

## フェーズ1: 勝敗判定とリスタート (まずここから実装)

### 1.1 ゲーム状態管理
- 新変数 `gameState`: `'playing'` | `'win'` | `'lose'`
- `step()` 内のゴール判定後、`scoreP === 10` なら `'win'`、`scoreA === 10` なら `'lose'` に遷移
- `'win'` / `'lose'` 中は:
  - `step()` の物理更新をスキップ(パドル位置の更新も停止)
  - パック・パドルは画面上の最後の位置に残す
  - `aiNoise` などの内部状態更新も停止

### 1.2 勝敗演出オーバーレイ (canvas 描画)
- 画面全体に半透明オーバーレイ
- 中央に大きく「かち！」/「まけ...」(高齢者向けに平易な表記)
- スコア表示は維持
- 「ホイールをまわすと次の試合へ」のヒント表示
- 簡単なアニメーション:
  - WIN: 黄色〜オレンジの光が中央から脈動 (sin波で alpha 変動)
  - LOSE: 青〜グレーの静かなフェード
- 凝ったパーティクル(紙吹雪等)は後回し、まず動く土台を作る

### 1.3 リスタート操作
- `gameState !== 'playing'` のとき、ホイール入力(`Math.abs(e.deltaY) > 0`)を検出すると:
  - `scoreP = 0; scoreA = 0`
  - `reset()` でフェイスオフ
  - `gameState = 'playing'`
- 連続ホイール検知の暴発防止: 直前のゲームオーバー突入から500ms以内はリスタート無効(クールダウン)
- R キーも従来通り試合中リセットに使えるよう残す(ゲームオーバー中も有効)

### 1.4 既存挙動への影響
- 試合中のホイールはパドル操作のまま
- 試合中の F キー(校正)、設定モーダルの開閉はそのまま動作
- ゲームオーバー中も設定モーダルは開ける(難易度変更などをして次戦へ)

## フェーズ2: 音声アセット作成

### 2.1 効果音 (パドル・ゴール)
配置: `games/table-hockey/audio/`
- `paddle_hit.wav` — パックがパドルに当たる「コツン」音 (~80ms)
- `goal_player.wav` — プレイヤー得点時のポジティブな短音
- `goal_cpu.wav` — CPU得点時の低めの短音 (もしくは `goal_player.wav` を共用)

調達方法: 既存のフリー素材から選定、もしくは Web Audio で軽く合成して WAV 化。ライセンスフリーで使えるものを優先。

### 2.2 TTS ボイス (ずんだもん via VOICEVOX)
配置: `games/table-hockey/audio/`
- `voice_win.wav` — 「やったね！かちましたのだ！」など
- `voice_lose.wav` — 「ざんねん…次はがんばろうなのだ」など

生成スクリプト: `games/table-hockey/generate_voices.py`
- `janken-party/generate_result_voices.py` をコピー改変
- Speaker ID 3 (ずんだもんノーマル) を流用

## フェーズ3: 音声結線とON/OFF設定

### 3.1 AudioContext 起動
- ブラウザの autoplay 制限のため、最初のユーザー操作 (ホイール / キー / クリック / 歯車タップ) で `AudioContext` を初期化
- 各 .wav は最初に1回だけロード、`AudioBuffer` にデコードしてキャッシュ

### 3.2 再生タイミング
| イベント | 再生する音 |
|---|---|
| プレイヤーがパドルでパックを返す | `paddle_hit.wav` |
| CPUがパドルでパックを返す | `paddle_hit.wav` (同じ音) |
| プレイヤー得点 | `goal_player.wav` |
| CPU得点 | `goal_cpu.wav` |
| プレイヤー勝利確定 | `goal_player.wav` → 少し遅らせて `voice_win.wav` |
| プレイヤー敗北確定 | `goal_cpu.wav` → 少し遅らせて `voice_lose.wav` |

### 3.3 設定モーダルに音ON/OFF
- 「ラリーで徐々にパックが加速」のすぐ下に「音 ON/OFF」チェックボックス追加
- デフォルトON
- OFF 時は `paddle_hit.wav` などの再生をスキップ(ボイスも含む)

### 3.4 音量バランス
- パドル音は頻繁に鳴るので控えめ (0.4 程度の gain)
- ゴール音とボイスはしっかり聞こえる (0.8 程度)

---

## 実装順序

1. **フェーズ1 完了 → コミット**(このターンで実装)
2. フェーズ2.1: 効果音ファイルの調達方針を相談
3. フェーズ2.2: 生成スクリプトを書いてボイス生成
4. フェーズ3: 結線とON/OFF

各フェーズ完了ごとにコミット & push。
